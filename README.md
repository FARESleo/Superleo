# 📊 Crypto Market Tool

أداة مفتوحة المصدر لتحليل **سعر العملات الرقمية + Open Interest + Long/Short Ratio**  
لمعرفة إن كان هناك "⚠️ فخ صعود" من صانع السوق أم حركة صحية ✅.  

---

## ✨ المميزات
- 🎨 واجهة عصرية مبنية بـ **Streamlit + Plotly**
- 📊 رسوم تفاعلية (تكبير، تمرير الفأرة لعرض البيانات، حفظ الصور)
- ⚡ تحليل تلقائي يعتمد على:
  - **السعر (Candlesticks)**
  - **Open Interest**
  - **Long/Short Ratio**
- 🖥️ تصميم متجاوب (يدعم سطح المكتب والهاتف)
